Conversations

The list appears only once there is more than one agent. With Otto alone, the app opens straight into its thread.

Otto’s thread

Otto stays the lead. Telegram and WhatsApp still talk only to Otto; it brings pips in when needed.

Group chat

Talk to several pips together. Sender names keep replies clear; @mentions direct the next request.

Handoff

A quiet system line opens the exchange. A failed handoff stays in place with a retry and a clear explanation.

New pip

Give a pip a name, a job and a colour. Memory and logins are shared; its instructions are its own.

Pip details

See its job, schedules and access. Sleeping saves the shared Claude allowance; pausing also stops scheduled work.

Mac conversations

Pips sit above Jobs and the existing navigation. Otto remains the place to ask for work across several pips.

Mac group chat

The side panel shows who is working and who needs you. Only Otto stays running; pips start when needed.

Inside the handoff

The system line opens the messages shared for this task. This exchange shows the failed handoff.
